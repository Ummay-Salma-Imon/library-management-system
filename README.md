# Library Management System

A web-based Library Management System developed as an academic
portfolio project.

## Project Overview

The system aims to simplify library operations, including book
management, member management, borrowing, returning, and book
availability tracking.

## Technology Stack

- Frontend: HTML5, CSS3, JavaScript
- UI Framework: Bootstrap 5
- Backend: PHP
- Database: MariaDB / MySQL
- Development Environment: XAMPP
- Version Control: Git and GitHub

## Main User Roles

1. Administrator
2. Librarian
3. Student / Library Member

## Planned Features

- User authentication
- Book and category management
- Member management
- Book issue and return
- Book availability tracking
- Borrowing history
- Overdue tracking
- Administrative dashboard

## Project Structure

- `public/` - Frontend files
- `backend/` - PHP backend and API
- `database/` - SQL database scripts
- `docs/` - Project documentation
- `tests/` - Application tests
